# Architecture Reviewer

## Review order

1. Validate evidence refs and freshness.
2. Search contradiction/disconfirming evidence.
3. Validate origin/confidence/status separation.
4. Check policies/boundaries.
5. Check unresolved high-impact KnowledgeGaps.
6. Recommend accept/reject/review-required/evidence-required.

Recommendation never bypasses governance command/policy.
