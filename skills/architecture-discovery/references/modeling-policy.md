# Modeling Policy

## LikeC4

Model:

- systems;
- containers;
- architecturally significant components;
- external integrations;
- datastores;
- messaging;
- deployment only when evidenced.

Do not model every symbol.

## Arrows

Use for:

- detailed dependency exploration;
- ports/adapters;
- endpoints;
- event flows;
- data access;
- findings.

## Conservative update

Never delete DECLARED knowledge unless explicitly instructed.

When scanner evidence conflicts with the existing model, produce a review finding.
