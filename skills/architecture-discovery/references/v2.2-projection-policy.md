# Projection Policy V2.2

1. Understand the requested visual intent.
2. Prefer semantic routing over explicit tool choice.
3. Use LikeC4 for architecture.
4. Use Arrows for curated graph exploration.
5. Use draw.io for general technical diagrams.
6. Use JSON Canvas for knowledge maps and investigations.
7. Use GraphML for medium/large graph analysis.
8. Never write projection files into the source repository.
9. Treat projection files as recreable artifacts.
10. Never overwrite a manually modified projection silently.
