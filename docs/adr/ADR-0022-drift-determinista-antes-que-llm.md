# ADR-0022: Drift determinista antes que LLM

- Status: Accepted
- Date: 2026-08-31

## Context

Reglas conocidas no requieren IA.

## Decision

Behaviors/policies deterministas; LLM explica/proponen.

## Consequences

### Positive

Menor coste y más reproducible.

### Negative / Trade-offs

Sólo cubre reglas expresables.

## Revisit when

Principio permanente salvo imposibilidad técnica.
