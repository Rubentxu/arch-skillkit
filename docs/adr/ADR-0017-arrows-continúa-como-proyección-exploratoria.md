# ADR-0017: Arrows continúa como proyección exploratoria

- Status: Accepted
- Date: 2026-08-31

## Context

Arrows aporta detalle sin necesidad de gobernar estado.

## Decision

Mantenerlo derivado y recreable.

## Consequences

### Positive

Renderer sustituible.

### Negative / Trade-offs

Edits manuales no persistidos automáticamente.

## Revisit when

Si aparece bidireccionalidad explícita.
