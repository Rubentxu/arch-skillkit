# ADR-0016: LikeC4 pasa a ser proyección

- Status: Accepted
- Date: 2026-08-31

## Context

V1 lo usaba como modelo canónico.

## Decision

Supersede ADR-0005; generar LikeC4 desde Architecture World.

## Consequences

### Positive

LikeC4 queda enfocado en arquitectura.

### Negative / Trade-offs

Ediciones manuales requieren reconciliación.

## Revisit when

Si se diseña authoring bidireccional.
