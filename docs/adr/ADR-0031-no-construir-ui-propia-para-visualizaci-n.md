# ADR-0031: No construir UI propia para visualización

- Status: Accepted
- Date: 2026-08-31

## Context

El ecosistema ya ofrece aplicaciones maduras para arquitectura, grafos, knowledge maps y diagramación.

## Decision

ArchSkillKit seguirá generando ficheros para aplicaciones externas.

## Consequences

### Positive

Máximo valor con mínimo código y mantenimiento.

### Negative / Trade-offs

Experiencia fragmentada entre varias aplicaciones.

## Revisit when

Sólo si un workflow crítico no puede cubrirse razonablemente con las aplicaciones existentes.
