# ADR-0028: Adoptar JSON Canvas para mapas de conocimiento

- Status: Accepted
- Date: 2026-08-31

## Context

Se necesita una representación file-based para mindmaps, investigations y notas conectadas.

## Decision

Usar JSON Canvas como formato core; Obsidian es un consumidor recomendado pero no obligatorio.

## Consequences

### Positive

Formato simple, abierto y desacoplado de una única aplicación.

### Negative / Trade-offs

Layouts complejos requieren heurísticas.

## Revisit when

Si aparece un estándar abierto claramente superior.
