# ADR-0021: Fork/diff para propuestas arquitectónicas

- Status: Accepted
- Date: 2026-08-31

## Context

Hipótesis no deben cambiar el estado aceptado.

## Decision

Usar forks ActiveGraph para propuestas y evals.

## Consequences

### Positive

Aislamiento, diff y auditoría.

### Negative / Trade-offs

Lifecycle más complejo.

## Revisit when

Si fork semantics no encajan en uso real.
