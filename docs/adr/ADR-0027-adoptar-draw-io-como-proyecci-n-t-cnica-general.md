# ADR-0027: Adoptar draw.io como proyección técnica general

- Status: Accepted
- Date: 2026-08-31

## Context

LikeC4 y Arrows no cubren bien diagramas técnicos heterogéneos y libremente editables.

## Decision

Añadir `.drawio` como proyección core para diagramación técnica general.

## Consequences

### Positive

Aplicación madura, editable y de propósito amplio.

### Negative / Trade-offs

El XML es más complejo que JSON Canvas/GraphML.

## Revisit when

Si el coste de generación supera el valor observado.
