# Architecture Decision Records

## Estados

- Proposed
- Accepted
- Superseded
- Rejected

## Regla

No editar retrospectivamente una decisión significativa.

Si cambia:

1. crear nuevo ADR;
2. marcar el anterior como Superseded;
3. enlazar ambos.
