# Release v0.5.0 — archskillkit-distribution-v1

> **Cycle**: `p-f58d41952fdf56c1/archskillkit-distribution-v1`
> **ADR**: [ADR-0063](../adr/ADR-0063-archskillkit-distribution-v1.md)
> **Tag**: `v0.5.0`
> **Date**: 2026-09-09

## Summary

This release closes the v0.5.0 distribution hardening cycle
(`archskillkit-distribution-v1`). It addresses five classes of
distribution drift that previously blocked a clean release:

* **Version surfaces** now share `python/pyproject.toml::version` as
  the single source of truth. Lint gate fails on drift.
* **Verify defaults** in `run-verify.sh` and `justfile` no longer
  hard-code an obsolete version.
* **Runtime install** is atomic with a last-known-good rollback
  anchor.
* **Attestation policy** is explicit per-artifact (self-attested vs
  upstream).
* **Supported platforms** are documented and enforced by tests.

## What changed

### Code

* `python/src/archskillkit/__init__.py` — `__version__` derived from
  `importlib.metadata.version("archskillkit")` with a fallback for
  source checkouts.
* `python/src/archskillkit/runtime.py` — runtime installer now runs
  `_fix_venv_shebangs` BEFORE `os.replace(staging, final)` and
  preserves the prior install under
  `.previous-<version>-<platform>`.
* `python/src/archskillkit/runtime_manifest.py` — `AttestationPolicy`
  gains an optional `warning` field.
* `scripts/release/generate-runtime-manifest.py` — upstream artifacts
  carry `attestation.warning` explaining the hash-only integrity
  guarantee.
* `scripts/release/sync-versions.py` — checks wheel filename version
  against `pyproject.toml::version` (regex fix: `[^-]*` captures
  inner dots; previously `[^.-]*` excluded them silently).
* `scripts/verify/run-verify.sh` — `_resolve_default_version()` reads
  `dist/archskillkit-*.whl` first, falls back to `pyproject.toml`.
* `justfile` — `verify-release` and `verify-release-full` no longer
  hard-code `version="0.3.0"`.

## Upgrade notes

* **Breaking (T-1)**: `__version__` resolves from `importlib.metadata`.
  A source checkout without an installed wheel now reports
  `"0.0.0+unknown"` instead of a stale literal.
* **Breaking (T-2)**: `verify-release` and `verify-release-full` no longer
  default to `version=0.3.0`. They default to whatever wheel is in
  `dist/`. Pass `version=0.4.0` explicitly if you must target an
  older release (a `WARN` will be emitted).
* **Non-breaking (T-3)**: runtime install creates a `.previous-<v>-<p>`
  sibling on every successful install. Operators can promote the
  previous install back by `mv` if the new install is rejected.
* **Non-breaking (T-4)**: upstream artifact entries in the runtime manifest
  now carry an `attestation.warning` field. The runtime behavior is
  unchanged (still hash-only integrity for those artifacts); the
  field is informational for operators.
* **Non-breaking (T-5)**: `docs/v2/25-supported-platforms.md` is now the
  canonical matrix. Operators hitting `PLATFORM_UNSUPPORTED` should
  consult that doc before opening a feature request.
* **Non-breaking (T-6)**: `mise run lint` now fails on any version
  drift between `pyproject.toml`, `version.json`, and wheel filenames.
* **Non-breaking (T-7)**: ADR-0063 captures the seven design decisions
  (D-1..D-7) made during this cycle.
* **Non-breaking (T-8)**: This release notes document is the operator-
  facing changelog. The release is cut as `v0.5.0` once the verify
  gate is green.

## Deferred

Tracked in `docs/v2/87-v2.5-backlog-deferred.md`:

* macOS and Windows support.
* linux/armv7, linux/riscv64, linux/ppc64le.
* Musl-based Linux distributions (Alpine).
* Auto-deletion of stale wheels in `dist/`.
* Attestation gating for upstream artifacts (would block all
  installs).
