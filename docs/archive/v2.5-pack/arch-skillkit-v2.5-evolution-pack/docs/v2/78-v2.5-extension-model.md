# V2.5 Extension Model

## 1. Objetivo

OCP sin convertir el kernel en un plugin framework arbitrario.

## 2. SPIs permitidas

### EvidenceProvider

Produce evidencia normalizada y provenance.

### SemanticIndexProvider

Resuelve símbolos/edges con capacidades declaradas.

### ProjectionAdapter

Transforma snapshot/view model en artefacto recreable.

### ViewerAdapter

Abre/embebe artefactos sin cambiar semántica.

### PolicyPack

Declara reglas, severidades y metadatos de gobernanza.

## 3. Capability descriptor

Cada extensión declara:

- name;
- version;
- schema version;
- capabilities;
- deterministic yes/no;
- supported languages/frameworks;
- required external tools;
- provenance fields.

## 4. No-go

Un plugin no recibe acceso arbitrario a `ArchitectureWorld.graph`.

Mutaciones pasan por ports/commands explícitos.

## 5. Compatibilidad

Contratos versionados y tests de contrato por SPI.
