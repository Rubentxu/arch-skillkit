# V2.4 Application API, CLI and MCP Contracts

## 1. Regla

CLI, MCP y Control Plane deben invocar Application API; ningún adapter debe invocar otro adapter como arquitectura primaria.

## 3. CLI target

Conservar comandos existentes. Añadir de forma incremental:

```text
ark status
ark schema [command|object]
ark explain <subject>
ark why <subject>
ark impact <subject>
ark ask <question>
ark history
ark changes --since <snapshot|commit>
ark view [--format F] [--with VIEWER]
ark viewers
ark gate
ark simulate ...
ark guard ...
ark investigate ...
ark mcp
ark serve
```

No añadir todos en `cli.py` con un único cascade. Refactor previo a command handlers/adapters pequeños.

## 4. JSON contracts

Cada output machine-readable incluye:

- `$schema` o `schema` estable;
- `schema_version`;
- `snapshot_id` si aplica;
- errors tipados;
- no depender del texto human-readable.

`ark schema` expone schemas de outputs y objetos relevantes.

## 5. Typed Action Suggestions

`status` devuelve actions, no shell strings como contrato:

```yaml
action_id: discover
reason_code: INDEX_STALE
parameters:
  scope: app
preconditions:
  - project_initialized
mutation_scope: workspace
risk: low
```

El CLI puede renderizar `ark discover ...`.

## 6. MCP

Target: specification 2026-07-28.

El core MCP actual es stateless; el estado de aplicación se representa mediante handles explícitos (`session_id`, `snapshot_id`, `proposal_id`).

### Tools read-only default

- `get_status`;
- `get_snapshot`;
- `search_code`;
- `search_evidence`;
- `get_context_pack`;
- `explain_element`;
- `analyze_impact`;
- `get_drift`;
- `get_history`;
- `list_knowledge_gaps`;
- `generate_projection` puede ser workspace-write pero no domain-write.

### Propose capability

Opt-in:

- `start_investigation`;
- `submit_inference_candidate`;
- `simulate_change`;
- `create_proposal`.

### Admin capability

Explicitamente deshabilitada salvo configuración:

- `promote_proposal`;
- `create_waiver`.

## 9. Dependency policy

SDK MCP como extra opcional, p.ej. `archskillkit[mcp]`, aislado en delivery adapter. Pin major compatible con spec seleccionada y lock transitives en `uv.lock`.

## 10. Errors

Definir códigos estables, p.ej.:

- PROJECT_NOT_INITIALIZED;
- SNAPSHOT_STALE;
- SESSION_STALE;
- EVIDENCE_NOT_FOUND;
- PROJECTION_UNSUPPORTED;
- VIEWER_UNAVAILABLE;
- POLICY_DENIED;
- PROMOTION_REQUIRES_REVIEW;
- BUDGET_EXCEEDED;
- CAPABILITY_DISABLED.

## 11. Security

MCP read-only por defecto. Ningún cliente externo obtiene capacidad de `promote` por el hecho de poder conectarse.
