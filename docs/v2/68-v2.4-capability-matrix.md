# V2.4 Capability Matrix

## Projection formats vs viewers

| Format | Primary purpose | Embedded candidates | Local/external candidates | Round-trip priority |
|---|---|---|---|---|
| LikeC4 | formal architecture/C4 | LikeC4 Web Component | LikeC4 server/VS Code | medium |
| Arrows | property graph exploration | none required | VS Code Arrows / arrows web | medium |
| draw.io | technical editable diagram | diagrams.net embed | draw.io Desktop/VS Code | high |
| JSON Canvas | knowledge/investigation map | optional custom viewer later | Obsidian/compatible apps | medium |
| GraphML | graph exchange/analytics | none required | yEd/Gephi/Cytoscape | low semantic import initially |
| Excalidraw | sketch/proposal/explanation | Excalidraw component | Excalidraw apps | high if adopted |
| Mermaid/DOT/D2/PlantUML | lightweight interchange/docs | browser/doc renderers | ecosystem tools | low |

No application is canonical; ArchitectureWorld is canonical knowledge.
