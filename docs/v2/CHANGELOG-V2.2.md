# Changelog V2.2

> **Scope:** this changelog records changes to the V2.2 specification and design package. Entries here are not evidence that a production implementation exists. The authoritative implementation tracker is [`STATUS.md`](STATUS.md).

## Added

- VisualIntent abstraction.
- Projection Router.
- Common ProjectionAdapter contract.
- draw.io core projection.
- JSON Canvas core projection.
- GraphML core projection.
- Cytoscape/Gephi/yEd consumption model.
- projection lifecycle and stale detection.
- manual edit protection.
- projection security/redaction profiles.
- roadmap, milestones, UAT and spikes for projection applications.
- ADR-0026 through ADR-0031.

## Preserved

- Python + ActiveGraph only.
- ActiveGraph Event Log as source of truth.
- Code Index as regenerable evidence graph.
- LikeC4 and Arrows.
- repository read-only.
- XDG workspaces.
