# V2.4 Decisions, Assumptions and Deferred Work

## Accepted direction for implementation

- Evolutivo se denomina V2.4.
- Python + ActiveGraph sigue siendo stack propio.
- Event log sigue source of truth del ArchitectureWorld.
- CodeIndex no se reemplaza por una graph DB general.
- Application Core por encima de CLI/MCP/HTTP.
- Multi-format/multi-viewer es requisito de producto.
- Control Plane integra viewers; no crea renderer propio.
- LLM = candidate knowledge, no trusted writer.
- Skills continúan provider-neutral.
- MCP es opcional y read-only default.
- Fitness Profile multidimensional.
- Counterfactual simulation usa forks.
- Learning progresivo mediante sensor distillation.

## Decisiones condicionadas a spikes

- React/precompiled frontend vs vanilla shell.
- Excalidraw como adapter productivo.
- RunLedger implementation concreta.
- GraphStore adicional.
- signed architecture snapshots.
- incremental/watch.

## Deliberadamente fuera de V2.4 core

- SaaS multi-tenant;
- remote collaborative editing;
- distributed agents runtime;
- generic workflow engine;
- own graph renderer;
- automatic source-code modification;
- Go rewrite;
- “AI decides architecture” mode.
