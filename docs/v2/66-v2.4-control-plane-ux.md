# V2.4 Control Plane UX Specification

## 1. Purpose

El Control Plane es un **Architecture Explorer + Governance Console + Viewer Hub**. No es un IDE ni un editor gráfico propio.

## 2. Information architecture

### Home / Snapshot

- project/revision;
- freshness;
- Architecture Coverage;
- open drift;
- open Knowledge Gaps;
- Fitness Profile;
- typed suggested actions.

### Explore

- architecture element/relation search;
- selected projection/viewer;
- evidence panel;
- confidence/origin/status;
- history/first seen/last changed;
- related gaps/findings/decisions.

### Changes

- snapshot/commit selector;
- ArchitectureDelta;
- added/removed/changed relations;
- affected policies;
- impact entry points.

### Investigations

- AgentRun;
- goals/tasks;
- candidate hypotheses/claims;
- evidence requests;
- prompt/skill/model provenance;
- review decisions.

### Governance

- drift findings;
- proposals;
- waivers/debt;
- simulation result;
- promotion gates.

### Runs

- RunLedger;
- timings;
- tools/sensor revisions;
- artifacts/hashes;
- trace.

## 3. Viewer Hub

Selector conceptual:

```text
Projection: [LikeC4 v]  Viewer: [Embedded v]
[Regenerate] [Open external] [Export] [Evidence overlay]
```

Para GraphML:

```text
Projection: GraphML
Viewer: yEd | Gephi | Cytoscape | system default
```

## 4. Evidence-first interaction

Toda selección importante tiene acceso a:

- Why?
- Evidence
- Confidence
- Origin
- Changes
- Impact
- Open gaps

No esconder provenance detrás de una página secundaria.

## 5. Unknowns

Mostrar lo que el sistema no conoce:

- unmapped areas;
- low-confidence claims;
- unsupported constructs;
- missing sensor coverage;
- evidence stale.

Una UI que sólo enseña arquitectura “bonita” produce falsa confianza.

## 6. LLM interaction

Evitar una caja de chat omnipresente. Acciones contextuales:

- Investigate this gap;
- Explain this relation;
- Enrich this projection;
- Review contradictory evidence;
- Simulate a change.

Cada acción crea/usa AgentSession y queda trazada.

## 7. Editing

Presentation edits pueden persistir en PresentationProfile. Semantic edits deben mostrar delta y botón “Create proposal”, nunca “Save architecture” directo.

## 8. Progressive disclosure

Default para humanos: arquitectura + estado + evidence básica.

Advanced panels: raw claim graph, event ids, prompt hashes, sensor revisions, detailed trace.
