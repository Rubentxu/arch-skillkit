# V2.5 Roadmap

## Estrategia

V2.5 es un hardening evolutivo más Change Intelligence. No avanzar por número de
features. Cada milestone tiene gate objetivo y UAT.

## M0 — Verification Baseline

Objetivo: medir el estado físico actual.

Deliverables:

- architecture contracts;
- deterministic AST verifier;
- baseline reviewado;
- quality gate catalog;
- traceability matrix;
- wheel smoke test plan.

Exit:

- mismo commit produce mismo report;
- no-new-architecture-debt gate activo;
- baseline versionado.

## M1 — Governance Application API

Objetivo: eliminar el hotspot delivery->delivery más peligroso.

Deliverables:

- List/Create/Diff/Review/Promote/Reject Candidate use cases;
- typed results/errors;
- CLI/MCP/HTTP adaptados;
- eliminación de stdout-capture protocol.

Exit:

- Proposal flow parity;
- `delivery -> delivery` = 0 para governance;
- UAT25-010..014 PASS.

## M2 — Composition Root & Delivery Closure

Deliverables:

- `ArchSkillKitApplication`;
- central wiring;
- lifecycle;
- CLI strangler;
- HTTP/MCP sin construir world/index directamente.

Exit:

- delivery adapters sólo consumen Application API;
- application_api_coverage >= 90%;
- no nuevas instanciaciones de persistence en inbound adapters.

## M3 — ActiveGraph Boundary & Ports

Deliverables:

- ActiveGraph outbound adapter;
- repository contracts;
- `world.graph` leakage eliminado;
- CodeGraphQueryPort;
- application exceptions independientes.

Exit:

- ActiveGraph imports/leaks = 0 fuera adapter;
- application concrete imports = 0.

## M4 — ArchitectureDelta & Change Intelligence

Deliverables:

- canonical ArchitectureDelta;
- `changes`;
- no-new-drift semantics;
- impact usa delta cuando procede;
- PR report.

Exit:

- delta deterministic UAT;
- real base/head fixtures;
- gate result explainable by delta.

## M5 — Code Intelligence Providers

Deliverables:

- CodeIndex facade decomposition;
- AstGrep/Semgrep provider contracts;
- optional SCIP spike/provider;
- provider capability/provenance.

Exit:

- provider contract suite;
- no domain/app dependency on SQLite implementation;
- precision/cost report.

## M6 — Context & Agent Efficiency

Deliverables:

- ContextQuery on ports;
- stale-session rules;
- delta-aware context;
- impact-before-edit and gate-after-edit workflow.

Exit:

- bounded context;
- evidence density improves against naive baseline;
- stale detection 100% fixture set.

## M7 — Learning Architecture

Deliverables:

- SensorCandidate;
- evaluation corpus;
- sensor promotion workflow;
- first learned deterministic sensor.

Exit:

- candidate -> deterministic rule with documented precision/recall;
- measurable LLM calls/tokens avoided.

## M8 — Federation Spike, not commitment

Sólo si existe necesidad real multi-repo.

Gate de decisión:

- >= 3 concrete UATs que no puedan resolverse adecuadamente repo-scoped;
- snapshot federation sin shared mutable DB;
- coste/valor documentado.
