## P-01 · LikeC4 managed server (navegador)

El viewer `likec4-server` (MANAGED_SERVER) lanza `likec4 start` y
registra el PID en el RuntimeRegistry.

```bash
# vía artefactos OSS ya generados:
scripts/oss/view.sh nextjs serve        # abre UI en http://localhost:5173

# o vía el comando V2.4 sobre cualquier repo con proyección:
archskillkit project --repo <repo> --format likec4
archskillkit view --repo <repo> --format likec4
```

**Esperado**: UI interactiva de LikeC4 con el modelo (87 elementos /
55 relaciones en el caso Next.js); zoom/navegación fluida; el proceso
queda registrado (`RuntimeRegistry.active()` lo lista) y `cleanup_orphans`
lo reapea si se mata.

**Evidencia**: captura del navegador + salida de
`python/.venv/bin/python -c "from archskillkit.runtime_state.runtime_registry import RuntimeRegistry; print(RuntimeRegistry().active())"`
mientras el server corre.

## P-02 · draw.io embed mode (round-trip base)

Página autocontenida generada desde el artefacto real; protocolo
postMessage oficial (`load` + `export xmlpng`) de embed.diagrams.net.

```bash
python3 scripts/uat/m1-proof/generate-drawio-embed.py \
  --drawio artifacts/oss/nextjs-20260902/project/drawio.drawio \
  --out artifacts/uat/m1/drawio-embed-proof.html \
  --source-revision ec847d82
(cd artifacts/uat/m1 && python -m http.server 8046)
# abrir http://localhost:8046/drawio-embed-proof.html
```

**Esperado**: iframe del editor carga → botón 1 carga la arquitectura
(87 elementos) → botón 2 exporta PNG (aparece en el panel + log del
protocolo `← export`). Ese export es la base del round-trip M5
(`export → ProjectionDelta → proposal`, docs/v2/54 §8) — aquí sólo se
prueba la integración.

**Evidencia**: captura con el diagrama cargado + el PNG exportado +
el log de eventos `load`/`export` visible.
