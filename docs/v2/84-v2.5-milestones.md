## M7 — Learning

Mandatory:
- `LEARN-NO-AUTO-ACCEPT-001`
- `SENSOR-EVAL-001`
- `SENSOR-ROI-001`

**Status: PARTIAL by design at v0.13.5** — see [`docs/adr/ADR-0052-m7-learning-audit.md`](../adr/ADR-0052-m7-learning-audit.md) for the full audit and the trigger criteria for closing the deferred gates.
- `LEARN-NO-AUTO-ACCEPT-001` PASS (`promote-sensor` requires `--min-precision` and `--min-recall` thresholds; there is no auto-accept path — verified in `delivery/cli/promote_sensor.py:129,135`).
- `SENSOR-EVAL-001` not in gate catalog. **Trigger criteria for closure** (ADR-0052 §"Trigger criteria"): (1) ≥1 sensor promoted to production scan rules, (2) fixture corpus committed, (3) evaluation is deterministic across runs. **None of these are met at v0.13.5** — no `git log` evidence of an end-to-end promote-sensor run against a committed corpus.
- `SENSOR-ROI-001` not in gate catalog, depends on `SENSOR-EVAL-001`. **Trigger criteria for closure** (ADR-0052 §"Trigger criteria"): (1) `SENSOR-EVAL-001` closed, (2) LLM call/token counter in the compilation pipeline, (3) ≥1 UAT scenario with measurable sensor-on/off delta, (4) ≥10% reduction with no per-scenario regression. **None of these are met at v0.13.5** — the compiler has no input-cost surface (only `ContextPack.metrics` output metrics).

## Regla universal

Un milestone = PASS sólo si:

1. todos los gates BLOCKING obligatorios pasan;
2. no hay UAT obligatoria BLOCKED;
3. evidence bundle existe y sus hashes validan;
4. baseline no crece;
5. STATUS/capability matrix se actualizan.
