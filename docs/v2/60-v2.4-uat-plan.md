# V2.4 UAT Plan

## 1. Filosofía

Cada UAT valida comportamiento observable del producto y produce evidencia reproducible. Unit tests no sustituyen UAT. Cada scenario registra:

- milestone;
- repo fixture/OSS target + commit;
- prerequisites;
- commands/API calls;
- expected outputs;
- artifact hashes;
- source repository before/after status;
- result PASS/FAIL/BLOCKED;
- evidence paths.

## 2. UAT-M0 — Product Kernel

### UAT24-001 Snapshot reproducibility

Given un event log/code generation/policy revision fijo, dos ejecuciones producen mismo snapshot digest.

### UAT24-002 Snapshot change sensitivity

Cambiar generation o accepted relation cambia digest y ArchitectureDelta lo explica.

### UAT24-003 Runtime state isolation

Lanzar/cerrar viewer crea RuntimeRegistry state pero `replay-verify` y world digest no cambian.

### UAT24-004 RunLedger

Tres runs quedan paginables y ordenables sin cargar payloads completos del world.

### UAT24-005 Hex boundary

Tests de arquitectura fallan si delivery adapter importa ActiveGraph engine directamente o accede `world.graph`.

## 3. UAT-M1 — Daily Driver/Viewers

### UAT24-010 Status state inference

Cold/unindexed/stale/healthy/proposal-open states producen typed actions esperadas.

### UAT24-011 Schema self-description

Outputs `status/explain/viewers` validan contra schemas publicados.

### UAT24-012 Evidence explain

Seleccionar una relación real devuelve lineage hasta file:line/sensor generation.

### UAT24-013 Viewer independence

Generar LikeC4/draw.io/GraphML con viewers desinstalados continúa PASS.

### UAT24-014 GraphML consumer

Abrir artifact real con al menos yEd, Gephi o Cytoscape y verificar nodos/edges/metadata básica.

### UAT24-015 draw.io embedded

Carga XML real, edición presentation-only, export; semantic world permanece idéntico.

### UAT24-016 draw.io semantic delta

Añadir/eliminar relación visual reconocible produce `ProjectionDelta` candidate, no mutación aceptada.

### UAT24-017 multi-viewer routing

Mismo GraphML puede abrirse con viewer preferido y fallback SystemDefaultViewer.

## 4. UAT-M2 — Context/Agents

### UAT24-020 Budget adherence

ContextPack no supera budgets configurados.

### UAT24-021 Source read policy

No se abre source fuera de refs resueltas; registrar bytes/lines.

### UAT24-022 Evidence density

Comparar tarea canónica contra naive baseline. Registrar facts/evidence-backed claims por 1k tokens.

### UAT24-023 Impact

Cambio de símbolo/elemento conocido identifica blast radius esperado en fixture.

### UAT24-024 KnowledgeGap

Pregunta sin evidence suficiente crea gap y evidence request, no hallucinated accepted relation.

### UAT24-025 AgentSession stale

Modificar world/code/policy invalida o marca stale la sesión.

## 5. UAT-M3 — Governance

### UAT24-030 Deterministic gate

Mismos snapshots/policies producen mismo JSON + exit code.

### UAT24-031 No new drift

Base limpio + head con nueva violación -> FAIL; violación preexistente sin nueva -> configurable PASS.

### UAT24-032 Waiver expiry

Waiver válido permite policy configurada; expirado falla.

### UAT24-033 SARIF

Reporte valida schema y un consumer reconoce location/rule/severity.

### UAT24-034 Architecture Delta real

Base/head de PR o commits reales produce delta correcto y provenance.

## 6. UAT-M4 — LLM/MCP/Simulation

### UAT24-040 MCP parity

CLI y MCP `explain/impact/context` contienen misma semántica/snapshot.

### UAT24-041 MCP default safety

Cliente MCP no puede promote/create waiver sin admin enable.

### UAT24-042 Candidate knowledge

Fixture LLM produce InferenceCandidate; accepted architecture no cambia hasta review/promote.

### UAT24-043 Prompt provenance

Candidate conserva prompt hash, skill revision, context pack hash y evidence refs.

### UAT24-044 Simulation isolation

`simulate` devuelve delta/policy results y base snapshot queda idéntico.

### UAT24-045 Contradictory evidence

Reviewer crea contradiction/review-required, no selecciona silenciosamente una versión.

## 7. UAT-M5 — Control Plane

### UAT24-050 Local security

Default bind sólo loopback; write endpoints protegidos/disabled.

### UAT24-051 Evidence navigation

Click/selection de architecture object navega a evidence/provenance.

### UAT24-052 Viewer swap

LikeC4 -> draw.io -> GraphML external sin cambiar Architecture World.

### UAT24-053 Governance UX

Semantic candidate desde projection puede convertirse en proposal y requiere review.

## 8. UAT-M6 — Learning

### UAT24-060 Sensor distillation

Tres o más discoveries equivalentes producen candidate; no auto-accept.

### UAT24-061 Sensor validation

Candidate sensor alcanza threshold acordado sobre positivos/negativos + OSS target.

### UAT24-062 Learning provenance

SensorPackRevision aceptada enlaza discoveries, prompt/skill y fixtures que motivaron su creación.

## 9. OSS matrix

Mantener Next.js como baseline existente y completar diversidad:

- TypeScript/Next.js;
- Rust/Axum;
- Python/Django;
- fixture Kotlin/Spring existente para regresión.

No declarar generalidad multi-language sólo con un target.

## 10. UAT gate por milestone

Un milestone no pasa con scenarios `BLOCKED` obligatorios salvo que el bloqueo esté explícitamente aceptado como spike/dependency externa y no oculte un requisito funcional.
