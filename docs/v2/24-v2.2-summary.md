# V2.2 — Projection Applications

## Objetivo

Ampliar la capacidad visual de ArchSkillKit sin construir UI propia ni acoplar el dominio a aplicaciones concretas.

## Decisión

Introducir una capa formal:

```text
Architecture World / Code Index
          │
          ▼
      VisualIntent
          │
          ▼
  Projection Router
          │
  ┌───────┼─────────────┬─────────────┬──────────────┐
  ▼       ▼             ▼             ▼              ▼
LikeC4  Arrows        draw.io      JSON Canvas     GraphML

GraphML consumers:
  Cytoscape
  Gephi
  yEd
```

## Qué aporta

- arquitectura normativa;
- grafo exploratorio;
- diagramación técnica general;
- mapas mentales/conocimiento;
- análisis de grafos grandes;
- layout/editing en aplicaciones maduras.

## Qué NO hacemos

- no creamos una UI propia;
- no integramos cada aplicación con código especializado si existe un formato estándar;
- no convertimos cada renderer en dependency core;
- no duplicamos conocimiento entre proyecciones.

## Principio de diseño

Las aplicaciones son **consumidores**.

La fuente de verdad sigue siendo ActiveGraph + Code Index.
