- [ ] ArchitectureSnapshot schema versionado y digest estable.
- [ ] Snapshot contiene git/code/world/policy revisions.
- [ ] RunLedger persiste run summaries sin mezclar logs en ArchitectureWorld.
- [ ] RuntimeRegistry sobre XDG runtime y orphan cleanup probado.
